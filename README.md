# Web Project - 2022

This is a project, part of "Web Development" class at Computer Engineering and Informatics Department,
University of Patras, Greece.

## What's it about

Utilize crowd-sourced data of users' check-ins to places and their COVID diagnoses,
along with Google's data about estimated amount of visitors.
I gave users information regarding possible contact they might have had with other people who had visited
the same place and were COVID-positive.

I used Node.js, Vue 3, Express.js, Tailwind CSS, MongoDB, ApexCharts.js, Leaflet.js and Mapbox.

## How to run it

Check the READMEs in [client](/client) and [server](/server).

Set up the .env files by copying the respective .env.example files, and filling
in the blanks.

Then, once it's up (client, server, and MongoDB), you can sign up with a username
and password, and navigate through the app. Username `admin` is special and opens
the admin panel.
